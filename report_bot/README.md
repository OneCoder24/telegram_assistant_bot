# 🤖 Telegram-бот для рабочих отчётов

Асинхронный Telegram-бот для ведения рабочих заметок и автоматической генерации структурированных отчётов с помощью LLM (Groq API).

## ✨ Возможности

- 📝 **Быстрый ввод заметок** — текст, голосовые сообщения, фото с подписью
- 🎤 **Распознавание речи** — автоматическая транскрипция голосовых через Groq Whisper
- 🤖 **Генерация отчётов** — структурированные отчёты через LLM (llama-3.3-70b)
- ⏰ **Автоотправка** — ежедневные отчёты по расписанию
- 💾 **Локальное хранение** — SQLite база данных
- 🆓 **Полностью бесплатно** — используется бесплатный тариф Groq API

## 📋 Требования

- Python 3.10+
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))
- Groq API Key (получить на [console.groq.com](https://console.groq.com/))

## 🚀 Установка

### 1. Клонируйте или скачайте проект

```bash
cd report_bot
```

### 2. Создайте виртуальное окружение

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux/Mac
source venv/bin/activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Получите Telegram Bot Token

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям (придумайте имя и username)
4. Скопируйте полученный токен

### 5. Получите Groq API Key

1. Зарегистрируйтесь на [console.groq.com](https://console.groq.com/)
2. Перейдите в раздел **API Keys**
3. Создайте новый ключ
4. Скопируйте ключ (показывается только один раз!)

### 6. Настройте переменные окружения

```bash
# Скопируйте пример конфигурации
cp .env.example .env

# Отредактируйте .env и заполните ваши ключи
```

Содержимое `.env`:

```env
# Telegram Bot Token (от @BotFather)
BOT_TOKEN=your_telegram_bot_token_here

# Groq API Key (от console.groq.com)
GROQ_API_KEY=your_groq_api_key_here

# Путь к базе данных (опционально)
DATABASE_PATH=bot.db
```

## 📱 Использование

### Основные команды

- `/start` — Приветствие и инструкция
- `/help` — Список всех команд
- `/report` — Отчёт за сегодня
- `/report yesterday` — Отчёт за вчера
- `/report 2024-01-15` — Отчёт за конкретную дату
- `/list` — Заметки за сегодня (быстрый просмотр)
- `/clear` — Удалить заметки за сегодня
- `/settime 18:00` — Установить время автоотправки

### Добавление заметок

**Текстовые заметки:**
Просто отправьте любое сообщение, не начинающееся с `/`.

**Голосовые заметки:**
Отправьте голосовое сообщение — бот распознает речь и сохранит текст.

**Фото с заметкой:**
Отправьте фото с подписью — подпись сохранится как заметка.

### Пример рабочего процесса

```
Вы: Настроил сервопривод на роботе-манипуляторе
Бот: ✓ Заметка сохранена (#1)

Вы: [голосовое] "Проблема с калибровкой датчика, нужна помощь"
Бот: ✓ Записал: Проблема с калибровкой датчика, нужна помощь
    (заметка #2)

Вы: /report
Бот: 🤖 Генерирую отчёт...
     📋 Отчёт за 15.01.2024
     
     ### ✅ Выполнено
     - Настроил сервопривод на роботе-манипуляторе
     
     ### 🐛 Проблемы и блокеры
     - Проблема с калибровкой датчика, нужна помощь
```

## 🔧 Настройка

### Изменение промпта для отчётов

Отредактируйте файл `prompts/report.txt`. Доступные плейсхолдеры:
- `{date}` — дата отчёта
- `{notes}` — текст заметок

### Изменение времени автоотправки

Используйте команду `/settime HH:MM` в боте или измените значение по умолчанию в `config.py`:

```python
DEFAULT_REPORT_TIME: str = "18:00"  # Измените на нужное время
```

## 🐛 Решение проблем

### Бот не отвечает

1. Проверьте, что бот запущен и нет ошибок в консоли
2. Проверьте `bot.log` на наличие ошибок
3. Убедитесь, что `BOT_TOKEN` корректный

### Ошибка "Не расслышал, продиктуй текстом"

1. Проверьте качество аудио
2. Убедитесь, что `GROQ_API_KEY` действителен
3. Проверьте лимиты Groq API (бесплатный тариф имеет ограничения)

### Ошибка при генерации отчёта

1. Проверьте подключение к интернету
2. Убедитесь, что `GROQ_API_KEY` не истёк
3. Проверьте `bot.log` для деталей ошибки

## 📊 Лимиты Groq API (бесплатный тариф)

- **Requests per minute:** 30
- **Requests per day:** 14,400
- **Tokens per minute:** 6,000
- **Tokens per day:** 500,000

Для личного использования этих лимитов более чем достаточно.
